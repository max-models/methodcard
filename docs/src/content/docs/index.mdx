## What is included

<CardGrid>
	<Card title="Package layout" icon="open-book">
		A `src/` layout with a console entry point, `pytest` tests and a `pyproject.toml` ready for PyPI.
	</Card>
	<Card title="Continuous integration" icon="rocket">
		GitHub Actions for tests, static analysis, notebook execution, documentation and PyPI publishing.
	</Card>
	<Card title="Examples" icon="document">
		Jupyter notebooks in `tutorials/` are executed and published as pages of this site, and
		complete Python scripts in `examples/` are shown with their plots.
	</Card>
	<Card title="API reference" icon="setting">
		Every module, class and function is documented from the docstrings with starlight-pydocs.
	</Card>
</CardGrid>
