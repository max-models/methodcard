## What it does

<CardGrid>
	<Card title="One source of truth" icon="pencil">
		A class (`NumericalMethod` mixin) or function (`@method`) declares its equations, order of
		accuracy, assumptions and references as literals, next to the code.
	</Card>
	<Card title="Docs" icon="open-book">
		A griffe extension adds a "Numerics" section to each method's API page, and
		`methodcard export` gives the catalogue page of the shared docs theme, without importing
		the code.
	</Card>
	<Card title="Tests" icon="approve-check">
		`method_suite("mypackage")` checks every card: SymPy rules against the implementation,
		observed against declared orders, and the docs against the runtime.
	</Card>
	<Card title="Jupyter" icon="seti:notebook">
		A method renders its card in a notebook; `describe()` prints it in a terminal.
	</Card>
</CardGrid>
